The problem

Pseudonymity is the investigator’s bottleneck.

Blockchains don’t reveal identity — but they reveal behaviour. In most cybercrime cases the investigator is handed an address, not a person. Those funds nearly always surface, eventually, at a regulated exchange or service: a Virtual Asset Service Provider (VASP). Under Indian law, a VASP that is reported to the FIU must respond to lawful disclosure and freeze requests.

The blocker is time. Mapping hops across BTC, ETH and Tron, then working out which VASP the wallet is closest to — that legwork sits between a complaint and a freeze request. An hour lost to tracing is an hour the target spends looking for an off-ramp.

How it works

Ingest, trace, score, report.

A deterministic pipeline — same input, same trace, same result. Designed to be re-run and audited.

01

Ingest wallet address

Accept an unknown address across BTC, ETH or Tron. Normalise chain-native records into a single temporal ledger.

02

Build & trace the graph

Reconstruct the transaction graph, follow fund flow, and fold in exchange deposit behaviours to infer peer clusters.

03

Score & rank VASP candidates

Rank the nearest regulated entities with calibrated confidence tiers so an analyst knows which leads are court-ready.

04

Generate the report

Produce an evidence-backed, exportable case file: trace path, scoring rationale and confidence — ready for lawful disclosure workflows.

What ships in the MVP

Built for investigations, not dashboards.

Each capability shortens the path between a raw address and an enforceable lead.

Multi-chain intake

BTC, ETH and Tron for the MVP. A new chain is a registry entry, not a bolt-on rebuild.

BTCETHTRON+ roadmap

VASP attribution scoring

Calibrated confidence tiers over clustering, flow proximity and behavioural signals — never a single opaque number.

Interactive fund-flow graph

Cytoscape on the front, Neo4j behind it. Pivot, isolate sub-graphs, and interrogate the hop before you trust it.

Mixer & obfuscation detection

Known mixer ingress, peel-chain and hopping patterns get a hard stop — not a footnote inside aggregate noise.

Tiered evidence reporting

System score and analyst review stay separate from the final verdict. The report always shows whose judgment made the call.

Lawful-disclosure ready

Every export maps to the formats Indian enforcement workflows expect — SAHYOG included, not assumed.

The stack

The stack we actually run.

Containerised services, graph-native storage, and a frontend built for field-level review.

  • Python / FastAPI ingestion API
  • PostgreSQL ledger + cases
  • Neo4j / NetworkX graph engine
  • Next.js analyst console
  • Cytoscape.js graph UI
  • Docker deployment
  • Redis task cache
