01 · HOW IT WORKS

From suspect address
to a prepared request.

Four review steps an investigator can follow.

  1. 01
    MAP THE MONEY TRAIL

    Trace the graph

    Follows transfers outward step by step. High-degree hub addresses are filtered out before anything is scored.

  2. 02
    DISTANCE, THEN SUPPORT

    Score it twice

    How close a match is, and how well supported it is, are scored independently and never blended. A mixer hit stops attribution and drops confidence to zero.

  3. 03
    EVERY RESULT EXPLAINED

    Explain in plain language

    Every candidate includes an evidence tier and a plain-language explanation of what was found and how it was scored.

  4. 04
    SAHYOG HANDOFF

    Route via SAHYOG

    An analyst reviews the result and prepares the disclosure or freeze request, routed through SAHYOG to the legal entity holding the case.

02 · CHAINS SUPPORTED

Six supported chains. One workflow.

Each chain follows the same path from suspect wallet to ranked VASP candidate. Providers are selected by configuration, so live chain access uses API keys and endpoints supplied in the environment; the bundled synthetic dataset keeps the same path reproducible without keys.

03 · EVIDENCE MODEL

Two numbers.
Never blended.

Proximity answers “how close”. Confidence answers “how well supported”. A near candidate with thin evidence stays flagged as uncertain. The confidence score is an uncalibrated average of six signals — not a probability, an identity finding, or a legal conclusion.

0 LOW 40 MEDIUM 70 HIGH 100

SAMPLE SCORE 78 · HIGH · MIXER HIT SETS CONFIDENCE TO 0

Evidence tier
Relative match strength, from a direct deposit at Tier 1 to a weaker clue at Tier 4.
Label agreement
Whether independent exchange labels agree on the owner cluster.
Address reuse
Funds landing on a reused exchange deposit address count as a supporting signal.
Cluster consistency
Whether the path stays inside one owner cluster.
Path integrity
Each hop must have a backing transaction; a mixer hit stops attribution and broken cross-chain paths are flagged.
Freshness
Recent activity counts more; trails older than 90 days lose weight.

04 · SAHYOG HANDOFF

Prepare the lawful request
for the relevant entity.

The SAHYOG gateway sits behind a single adapter interface, isolated so the rest of the pipeline is unaffected. Its API contract is not public, so the interface is defined and the routing is left to SAHYOG once I4C releases it.

  1. IN

    A suspect wallet address is submitted, from SAHYOG intake or the API directly.

  2. TRACE

    The engine traces the transfers, ranks the nearest VASP candidate, and attaches the evidence.

  3. OUT

    The result is packaged as an outbound message for SAHYOG, which routes it onward to the legal entity holding the case.
